# Assignment 2 – Execution evidence

The seven task folders were compiled locally using OpenJDK 21.0.12.1. The programs listed in Task01–Task07 were executed and their stdout was saved in the matching TaskXX-actual-output.txt files in this folder.

The benchmark values are one captured run from this environment. They are not universal performance guarantees; timings depend on hardware, JVM warm-up, garbage collection and system load. Re-run the benchmarks on the student's own computer if the submission requires measurements from that machine.

All Java source folders compiled successfully. Task01 initially exposed a printf format issue during the first run; the format was corrected in the repository, recompiled, and the displayed Task01 results are from the corrected run.

The PNG output-capture images supplied separately were rendered from the recorded stdout of these actual program executions. They are not photographs of the user's own computer or screenshots captured on the user's desktop.
